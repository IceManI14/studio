# **App Name**: Trailblazer Tracker

## Core Features:

- Location Tracking: Tracks user GPS coordinates throughout the day and displays visited locations on a map.
- Visit Logging: Allows users to log visits to companies at tracked GPS locations.
- Automatic Contact Info Retrieval: Leverages a tool to automatically scrape contact information for visited companies from the internet. Displays a confidence score.
- Manual Data Input: Enables users to manually add and edit additional data and notes about each company visit.
- Notes summary: Summarize visit notes using generative AI
- Data Export: Export recorded visits in CSV format.

## Style Guidelines:

- Primary color: A vibrant, active blue (#4285F4), symbolizing forward motion and discovery.
- Background color: Light grey (#F0F2F5), a desaturated tone of the primary color, provides a clean, non-distracting backdrop.
- Accent color: A warm orange (#FF9800) provides contrast and visual interest.
- Headline font: 'Poppins', a geometric sans-serif providing a contemporary feel for headlines and short text.
- Body font: 'Inter', a grotesque-style sans-serif providing a clean, readable body text.
- Simple, recognizable icons to represent data points like locations, companies, and visit details.
- Subtle animations to indicate activity, like a loading animation when scraping data, or a pulsing animation for current location.
